# design-system

ThePromptProtocol 设计系统仓库，包含品牌视觉规范文档与配套设计资源。

## 目录结构

- `design-system-cn.md` — 中文版设计规范，涵盖品牌 Logo、色彩系统、字体排版、图标、按钮组件、间距系统、阴影样式及品牌吉祥物形象等内容
- - `design-system-en.md` — 英文版设计规范
  - - `assets.zip` — 配套设计资源文件（图标、Logo 等原始素材）
   
    - ## 使用说明
   
    - 设计师与开发者可参考本仓库中的规范文档，确保产品视觉呈现与品牌标准保持一致。
